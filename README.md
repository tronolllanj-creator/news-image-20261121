A program that draws one 1024x1024 image summing up the world news of Saturday 21 November 2026 (Russian missiles hit Poland, Cyclone Akvan, ICJ Myanmar genocide ruling, S&P 500 correction, Trump-Xi-Putin summit, bank vendor cyberattacks)
A 1024×1024 front-page infographic dated Saturday 21 November 2026: a navy masthead reads 'THE WORLD IN ONE IMAGE', a huge headline reports Russian missiles hitting Poland, and five brief rows cover Cyclone Akvan, the ICJ's Myanmar genocide ruling, the S&P 500 correction, the Trump-Xi-Putin summit and bank cyberattacks, with an ALSO TODAY strip for COP31.
## How it was built
Generated by `generate_image.py` with three layout variants (1, 2, 3) using PIL.
## Run it
```sh
python3 generate_image.py 3
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
